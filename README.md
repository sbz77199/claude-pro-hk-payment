## 先說結論：付款這關，香港用戶過得了

香港的訂閱攻略裡有個說法：想用 Claude 要過三道關——網路環境、SMS 驗證、付款方式。前兩關屬於註冊階段的問題，第三關就是這篇的主題。

直接給答案：可以付。Claude Pro 的定價是每月 20 美元。用香港發卡的 Visa、Mastercard 或 American Express 付款時，銀行會自動按當日匯率把 20 美元折算成港幣扣款，連同外幣交易手續費，每月實際支出大約在 HKD 160 到 170 之間。這是攻略作者連手續費一起算的估算值，實際金額以銀行帳單為準。

官方訂閱通道目前支援兩類支付方式：

- 國際信用卡或扣賬卡（Visa、Mastercard、American Express）
- PayPal

AlipayHK、WeChat Pay HK、八達通這些本地電子錢包，暫時都不在支援名單裡。想訂閱，只能走卡片或者 PayPal，這點先有心理準備。

## 香港卡直付：流程很短，細節在卡上

直付的操作本身沒什麼難度，三步：

1. 登入你的 Claude 帳戶（還沒有的話先花一分鐘註冊）
2. 在側邊欄或設定頁找到 Upgrade to Pro，確認價格後繼續
3. 填入卡號、有效期、CVV 安全碼

第一次綁外幣卡時，部分銀行會發一組 OTP 驗證碼到手機。有實際走過流程的用戶提到，這類 SMS 有時要等 10 到 20 秒才到，別急著連點重發，稍等一下就好。付款即時生效，不會有漫長的審核等待。

真正決定成功率的是卡本身，這幾點值得留意：

- **開通網上外幣支付功能。** 扣賬卡（Debit Card）也可以，但必須先在銀行 App 裡開通國際支付權限，否則會直接報「卡片不支援此類購買」。
- **傳統大行卡比虛擬銀行卡穩。** 有長期測試不同卡片的使用者分享，部分虛擬銀行的卡在某些時段會觸發更嚴格的風控驗證，首選匯豐、渣打這類傳統銀行的卡片，成功率更高。
- **留夠餘額。** 系統自動處理換匯，確保卡裡有大約 170 港幣的可用空間，避免因為餘額不足卡在驗證環節。

不想直接綁卡的話，PayPal 是另一條被驗證過的路。有香港用戶用 PayPal 綁香港信用卡完成訂閱，流程和直付差不多，只是結帳時選 PayPal 再跳轉授權。

## 被拒了？先對照這幾種報錯

Anthropic 的收款走 Stripe 通道，而 Stripe 判斷一張卡能不能用，看的是卡號前 6 位的 BIN 碼。中國大陸發卡行的 BIN 會被直接按高風險處理，這也是 Anthropic 說明中心寫明「建議使用非中國發行信用卡」的原因。香港卡原則上不在這個攔截範圍，但風控並不是只看發卡地區，實際被拒的情況確實存在——連登討論區上就有用戶反映，Google Pay 和 Apple Pay 路線都被 Claude 拒過。

常見報錯可以對號入座：

**card_declined**
最常見的一種，九成和發卡地區或 BIN 段風控有關。換一張發卡行不同的卡，往往比反覆重試同一張有用。

**Your card does not support this type of purchase**
多半是卡沒開通國際美元扣款權限，去銀行 App 裡開通再試。

**扣了錢卻顯示支付失敗**
這是 Anthropic 計費系統的一個時序問題，錢會以預授權形式掛在卡上，一般 3 到 7 天自動釋放。訂閱狀態沒變的話，需要聯絡客服手動重置。

**past due 和 active subscription 同時出現**
訂閱進入了「殭屍態」，系統一邊認為你有訂閱、一邊不讓你用。換卡換瀏覽器都沒用，只能到說明中心提 support ticket，處理周期大約 5 到 10 個工作日。

還有一點容易被忽略：每次被拒都會留下記錄，同一張卡短時間內反覆重試，失敗次數多了反而更難過。兩次被拒之後就應該換路線，而不是第七次輸入同一組卡號。

## App Store 內購：成功率高，但少了一塊

直付和 PayPal 都走不通的話，App 內購是目前社區回饋成功率最高的一條路：用美區 Apple ID 加禮品卡餘額，在 Claude 手機 App 裡訂閱。資金走 Apple 的計費體系，Claude 這邊不攔截。

代價也很明確：App Store 的內購體系和 Claude Code 走的 Stripe 計費完全不通。手機上顯示 Pro，終端機裡的 Claude Code 還是 Free。需要用 Claude Code 寫程式的人，這條路直接排除；純粹在網頁和 App 裡對話的話，內購反而省心。

順帶一提，別把「App 內購」和「網頁端選 Apple Pay 結帳」混為一談。後者走的還是 Stripe，一樣會遇到前面那些風控。

操作層面的幾條規矩，比選哪家平台更重要：

- **帳單地址和卡的註冊資訊完全一致。** 姓名、地址、郵遞區號都按發卡平台提供的帳單地址填，不要填真實住址。
- **付款時的 IP 要和帳單地區對得上。** 帳單填的是美國地址，IP 卻跳到別的地區，Stripe 一眼就能看出不對。
- **一張卡只綁一個帳號。** 一卡多帳號是代購行為的高風險訊號，被判定後卡和帳號都可能被停用。
- **訂閱成功後關掉自動續費。** 虛擬卡餘額不足時扣款失敗，容易觸發卡片風控，下個月手動續費更穩。

## 訂閱前後的幾件小事

**公平使用政策要心裡有數。** Pro 不是無限用量，官方沒有公布具體閾值，但用腳本高頻呼叫、把帳號共享給多人這類行為，可能導致帳號被暫時限制。看到 Usage Limit Reached 的提示，稍作休息就好。

**隨時可以取消。** 在設定裡取消訂閱，下個月就不會再扣費，沒有綁一年合約這種事。

**開通銀行的即時消費通知。** 外幣交易每一筆都看得清清楚楚，每月扣款金額、匯率差異都好對帳。
